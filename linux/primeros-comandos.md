\# Primeros comandos de Linux



Este documento forma parte de mi laboratorio personal de ASIR.



\## Objetivo



Aprender comandos básicos de Linux y entender para qué sirve cada uno.



\## Comandos



\- pwd: muestra la ruta actual.

\- ls: muestra los archivos y carpetas.

\- cd: permite cambiar de directorio.

\- mkdir: crea una carpeta.
